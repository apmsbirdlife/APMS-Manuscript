This repository contains the data and code used to generate Figures 5, 6, S3, S5 and S6, and Tables S1 and S2 in Weideman et al. (in review).

Reference:
Weideman EA, Retief P, Faure JPB, Carpenter-Kling T, Christian M, Ludynia K, Pead J, Pistorius P, Sherley RB, Verrinder R, McInnes AM. (in review). An open-source automated monitoring system for non-invasive weighing of free-ranging penguins. Ecosphere.
